# Phase 27 - GUI Plot Preview

This phase adds in-app SVG plot preview to the PySide6 GUI.

## Implemented

- Added service helpers to select the primary plot and report artifact from run
  metadata.
- Added `Plot Preview` tab.
- Rendered saved SVG plots directly in the GUI with `QSvgWidget`.
- Kept the existing `Plot` button for opening the plot externally.
- Connected both new dry-runs and loaded indexed runs to the preview tab.

## Workflow

```powershell
ptm-gui
```

Then:

1. Run a dry-run with plot generation, or load an indexed run.
2. Open `Plot Preview`.
3. Confirm the SVG plot is shown inside the app.
4. Use `Plot` if an external viewer is preferred.

## Notes

Plot preview currently targets SVG artifacts generated by PyTransportMeasure.
Future work can add zoom controls, export actions, and multi-plot comparison.
